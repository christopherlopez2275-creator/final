# Study Room Occupancy Tracker
## Description

Written in C, keeps track of how many students are in a study room. Allows 
students to enter ande exit room while now allowing capacity over limit.
When room full, LED will indiciate. 

##How to Compile

gcc src/main.c -o occupancy 

## How to run

./occupancy

##Options 

1. Student enters
2. Student exits
3. Change room capacity
4. Exit program

##Hardware

-Raspberry Pi
-Breadboard
-LED
-Resistor
-Jumpers
